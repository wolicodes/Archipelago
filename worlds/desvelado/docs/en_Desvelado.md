# Desvelado

## Where is the options page?

The [player options page for this game](../player-options) contains all the options you need to configure and export a
config file.

## What is Desvelado?

Desvelado is a cute and short platformer game made by Vampi Team, available on Steam.

## What is randomized?

All Bonnie's bones in the bonus stages, and the map items at the end of each stage. Note that the vanilla maps will all
be unlocked by default, so the map items have been repurposed to unlock abilities instead.

## How does a seed play out?

Like said above, when starting a new seed, all maps will already be unlocked.

You can freely navigate to any stage you want via the map menu, but you will need to unlock abilities to reach the end
of some stages or the bonus stages.

## What is the goal?

The goal is generally to reach the end of the big vertical scroller at the right of the map, which gives you
access to Bonnie's Room. You can add more conditions to register the goal upon reaching this room,
like collecting all of Bonnie's bones, or completing all the stages.
